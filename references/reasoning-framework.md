# Inference workflow

URID is a proposed conceptual architecture for idiographic explanation, not an empirically unified theory. Start with a chronology and person IDs. Preserve the difference between an observed action, a quoted self-report, the user's appraisal, and an inferred motive. A user's certainty about someone is direct evidence about the user's interpretation, not the other person's mind.

Use the 13 phases in `SKILL.md`: parse → ledger → competing models → update → information audit → coarse-grain → dynamics → psychological semantics → narrative → pragmatics → countermodel → uncertainty → synthesis. In a short exchange these can yield a short answer. Do not invent detail to fill the template.

For a core inference, maintain 2–4 explanations and an open model boundary. Universal friendliness, special relational importance, and romantic interest may overlap; categorical entropy is appropriate only for an exclusive, exhaustive partition. For separate propositions update separate binary beliefs, recording that they may be dependent.

For each hypothesis preserve prior, posterior-like internal score if used, support, contradiction, source quality, context, recency, episode dependence, behavioural cost, confidence, and falsifiers. Never translate a subjective score into an apparently measured chance of love. Strong counterevidence can overturn an old model; age alone does not erase reliable historical evidence.

A switching rule must identify a trigger, goal, behaviour, and a competing explanation. “Soft socially; firm on deadlines when shared work is endangered” is informative if cross-context observations support it. “Independent but gentle” without conditions is not a mechanism.

Require a strongest ordinary countermodel and an update condition before major conclusions. Respect explicit labels and boundaries. Future openness is an unknown possibility, never permission to pressure someone. Offer natural observations or clear respectful questions, not secret tests. The least-assumptive account may end in uncertainty.

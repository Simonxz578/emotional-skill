# Person and relationship state

Person layers: relatively stable distributions (agency, autonomy, openness, conscientiousness, emotional intensity, reflection, uncertainty tolerance, attachment tendencies, narrative style); contextual modes (achievement, intimacy, threat, social exploration, solitude, conflict, recovery); current state (stress, workload, novelty, fatigue, loneliness, grief, attraction, uncertainty); development (old response → consequences → new rule → verified action).

Map each apparent contradiction to a conditional rule, not an identity label. Search for a rival state explanation: a firm deadline response might indicate temporary pressure rather than a general achievement policy. Mode names are descriptive hypotheses, not measured brain modules.

Keep these dimensions separate:

| Dimension | Evidence it concerns; inference it does not license |
|---|---|
| Warmth / comfort | Friendly tone and ease; not exclusivity |
| Trust / vulnerability | Disclosure and reliance; not consent or romantic intent |
| Admiration / specialness | Regard and baseline-specific importance; not commitment |
| Attraction / romantic attraction | Draw or explicitly romantic interest; not a future agreement |
| Romantic salience | Persistent romantic attention; can be asymmetric |
| Dependency | Reliance or felt necessity; not relationship quality |
| Reciprocity | Bidirectional investment; not identical feelings |
| Exclusivity | Explicit agreement and consistent conduct; not a heart emoji |
| Commitment | Intention to persist and enacted arrangements; not sunk cost alone |
| Future integration | Concrete place in plans; distinguish wish from implementation |
| Opportunity cost | Forgone alternatives/time; not proof of love |
| Repair motivation | Accountability and subsequent repair; not romance |
| Autonomy support | Respect for choice and separateness; not emotional distance |
| Secure-base function | Support for exploration and return; not a clinical attachment classification |
| Self-expansion | New capacities/perspectives through interaction; not destiny |

Describe current pattern, direction of change, missing evidence, and the next naturally informative event. A friends label and openness to a future conversation can coexist; honour the present boundary. A special undefined relationship can remain stable indefinitely.

Analyse actor effect, partner effect, and interaction effect separately. Reassurance-seeking → experienced pressure → delay → more uncertainty is a possible feedback loop, not proof one person is “anxious.” Disclosure → responsive acknowledgment → greater trust → more disclosure is another. Test both against chronology and baseline. Sparse anecdotes do not establish causal direction.
